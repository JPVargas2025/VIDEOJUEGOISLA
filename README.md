# VIDEOJUEGOISLA
Rescate en la Isla de Cristal es un videojuego de aventura y exploración desarrollado en Ingeniería Multimedia. El jugador debe sobrevivir y cumplir una misión cruzando tres biomas únicos (costero, tropical y geológico). Destaca por su diseño de UI inmersivo, físicas adaptativas y mecánicas específicas para cada ecosistema.
